## Yatay kurallar (tüm fazlar)
- Yuvarlama §13.6 (decimal, TRY 2 hane, AwayFromZero, komisyon+fee ayrı, net türetilir, 0 tolerans).
- Idempotency/concurrency §8/§19.15 (`ProcessedGatewayEvent`, state-machine, budget/entitlement reserve/consume/release).
- Migration append-only + legacy backfill + duplicate-seed koruması + effective-date overlap guard.

## FE — Admin panel (`react-admin-panel-foundation`) → `FE_ADMIN_*.md`
- CommissionRule CRUD (specificity + **conflict uyarısı**) · PlatformFeeRule CRUD · ProviderPlanPrice (List/Launch) ·
  PremiumProduct/Price · CustomerDiscountRule · CustomerBenefitBudget policy · ProviderCommissionBenefitRule ·
  **ProfitProtectionPolicy** (min katkı tutar/oran) · genişletilmiş **finansal raporlama dashboard'u** · refund/chargeback kuyruğu.

## FE — Provider portalı (`inktavia-marine-provider-web`) → `FE_PROVIDER_*.md`
- Mevcut Finans ekranları (payout/işlem/fatura — **hazır**) yeni snapshot kırılımını gösterecek (ServiceAmount/PlatformFee/
  CommissionBase; commission benefit; funding) · abonelikte **lansman vs liste** fiyatı · boost satın alma · işlem
  **İtirazlı** durumu · chargeback/clawback → **negatif bakiye/mahsup** şeffaf.

## Çapraz-kesit sertleştirme (go-live öncesi, ayrı task)
- **Messagebus generic consumer opt-out:** framework (`Aizen.Core.Messagebus/BuilderExtensions`) her `AizenEntity` için
  otomatik `AizenGenericConsumer<TEntity>` kaydediyor (opt-out yok). Bu, immutable/domain-authored entity'lerde
  (`PaymentEconomicsSnapshotEntity` ve genelde finansal entity'ler) generic ingestion'ın domain factory + invariant'ları
  bypass etme **latent riski** doğuruyor. Şu an dormant (kimse publish etmiyor). Öneri: Core.Messagebus'a
  `[NoMessagebusSync]`/marker ile **opt-out** ekle; domain-authored immutable Payment entity'lerine uygula. Framework
  geneli etki → **P-fazlarından ayrı, bilinçli task.** (BE-P1'de tespit edildi.)
