# 01 — Read Endpoint Catalog and Scan Controllers

1. Read `docs/admin-web-client/admin-panel-bff-endpoint-catalog.md`.
2. Extract every endpoint table.
3. Build an endpoint inventory grouped by controller/domain.
4. If a body/query param is ambiguous, inspect controllers and request DTOs under BFF and Application projects.
5. Do not invent endpoints.
6. Document any mismatch between catalog and controllers.
