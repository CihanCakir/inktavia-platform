# 02 — Generate AdminPanel BFF Endpoint Catalog

Create:

```text
docs/admin-web-client/admin-panel-bff-endpoint-catalog.md
```

For every endpoint include:

- Feature area
- Controller
- Action method
- HTTP method
- Route
- Purpose
- Request model
- Response model
- Query parameters
- Route parameters
- Required headers
- Auth requirement
- Downstream modules called
- Frontend screen/use case
- Status: Ready / Needs verification / Blocked / Future integration

Group by:

- Authentication / Identity Context
- Dashboard
- Users / Profiles / Roles
- ReferenceData / Options
- Vessels
- Vessel Documents / Media
- File Review
- Service Requests
- Offers
- Assignments
- Work Logs
- Completion
- Disputes
- Future Payment/Profile placeholders
