# 01 - Analyze Existing Postman Exports

Search for existing Postman collections, environments, and generation scripts.

Inspect and document:

- Keycloak token request scripts.
- Identity login request scripts.
- Token variable names.
- Header conventions.
- Base URL variables.
- Folder naming.
- Existing examples.
- Existing broken or inconsistent patterns.

Create:

```text
docs/postman/existing-postman-export-analysis.md
```

Do not generate new collections before completing this analysis.
