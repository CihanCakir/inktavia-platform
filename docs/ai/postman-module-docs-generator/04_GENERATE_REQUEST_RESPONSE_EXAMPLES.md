# 04 - Generate Request and Response Examples

For every endpoint, populate request and response content from actual code contracts.

Do not use empty `{}` for endpoints with request DTOs.

Inspect:

- Request DTOs
- Response DTOs
- Validators
- Enums
- Controller mappings
- Command/query handlers

Generate sample request bodies, params, route variables, response examples, and tests.

Update module endpoint inventories with:

- Request JSON sample
- Response JSON sample or schema
- Variables used
- Id extraction behavior
- Manual inference warnings
